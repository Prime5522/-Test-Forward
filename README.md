# Channel-to-Channel Forwarder Bot

A Telegram bot built with Pyrogram that allows each user to configure their own source and destination channels for message forwarding.

## Features

- User-specific channel configuration
- Start/Stop forwarding with buttons
- MongoDB for persistent storage
- Admin check for bot in both channels

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Replace credentials in `config.py`.

3. Run the bot:
```bash
python bot.py
```
